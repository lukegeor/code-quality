# LG0002: Remove Unnecessary Using Directive

| Property | Value |
| --- | --- |
| **Rule ID** | `LG0002` |
| **Title** | Remove unnecessary using directive |
| **Category** | `Readability` |
| **Default Severity** | `Warning` |
| **Enabled by Default** | Yes |
| **Code Fix Available** | Yes |

## Cause

A `using` directive was declared at file or namespace level that is not referenced anywhere in the source file.

## Rule Description

Unused `using` directives add visual clutter, slow down compilation and symbol resolution, and can lead to namespace collisions or ambiguous type references when new types or libraries are imported.

Removing unnecessary `using` directives keeps the file header focused and clean.

## How to Fix Violations

Remove the unreferenced `using` directive manually or apply the automated code fix.

### Non-Compliant Example

```csharp
// System is not referenced in this file
using System;
using System.Collections.Generic;

public class Sample
{
    public List<int> Numbers { get; } = new List<int>();
}
```

### Compliant Solution

```csharp
using System.Collections.Generic;

public class Sample
{
    public List<int> Numbers { get; } = new List<int>();
}
```

## How to Suppress Violations

If suppression is necessary, use `#pragma warning disable LG0002` or configure `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.LG0002.severity = none
```
